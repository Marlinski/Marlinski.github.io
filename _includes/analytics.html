{%- comment -%} Umami, self-hosted on sysiphe at stats.marlinski.org (sysiphe/umami/deploy). No cookies and no personal data, so no consent banner is required. Driven by `umami:` in _config.yml. Remove that block, or blank website_id, and this renders nothing at all — the site then behaves exactly as it did before analytics existed. GitHub Pages gives no environment variables, so config is the equivalent of the UMAMI_WEBSITE_ID env var the containerised sites use. The production guard is load-bearing, not a spare: Umami's collector does NOT validate hostname against the website's configured domain. /api/send records whatever hostname it is handed, so a local build would otherwise count. Project cards carry data-umami-event, which the script reports as a named event, so "which project did they click" lands in Events rather than in the page list. {%- endcomment -%} {%- if site.umami.website_id and jekyll.environment == "production" -%} {%- endif -%}

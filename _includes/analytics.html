{%- comment -%} Umami, self-hosted on sysiphe at stats.marlinski.org (sysiphe/umami/deploy). No cookies and no personal data, so no consent banner is required. Umami's script does not skip localhost the way GoatCounter's did, and the collector does NOT validate hostname against the website's configured domain — /api/send records whatever hostname it is given. The production guard below is therefore the only thing keeping `jekyll serve` out of the stats, not a belt-and-braces extra. Project cards carry data-umami-event, which the script reports as a named event, so "which project did they click" lands in Events rather than in the page list. {%- endcomment -%} {%- if jekyll.environment == "production" -%} {%- endif -%}
